## 太长不看版

这个项目希望解决的是，力量训练决策高度依赖个人上下文，但这些信息分散在训练 App、健康数据、周期记录、聊天和用户自己的记忆中，缺少一个能够长期理解并持续使用这些信息的系统。

我选择女性力量训练作为切入场景，是因为女性训练既遵循通用运动科学，又额外受到不同生理周期激素变化、营养和恢复需求等变量影响，同时这些因素存在明显个体差异。相比套用统一的女性训练规则，这类场景更适合通过长期个性化 Agent 解决。

产品形态上，我希望将 Agent 与结构化 App 结合。用户通过语音、文字、截图、历史训练记录和 Apple Health 等方式持续提供信息，Agent 负责理解和沉淀上下文，形成动态更新的个人训练模型；在实际训练中，它不仅给出建议，还能够直接生成或调整可执行的训练计划，并根据新的训练结果持续更新个人模型。

项目真正希望验证的不是 AI 能否回答健身问题，而是长期训练上下文是否能够让 Agent 给出更个性化、更低输入成本、也更容易执行的训练建议。最终希望形成的体验，是一个随着使用时间增加，越来越理解用户本人如何训练、如何恢复以及什么因素真正影响她训练表现的私人教练型 Agent。
